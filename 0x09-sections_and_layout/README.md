# 0x09 – Sections & Layout

> Compose components into complete, polished page sections.

## Why This Module Matters

Components are the building blocks. Sections are how users experience a page: hero, features, pricing, testimonials, footer.

This module trains you to assemble reusable components into intentional section layouts. You will practice hierarchy, spacing, and composition so your pages feel complete — not like disconnected widgets.

## Learning Goals

By the end of this module, you should be able to:

- Build a strong hero section
- Create feature and content sections with clear hierarchy
- Design a pricing section using cards and buttons
- Build a testimonials section
- Create a practical multi-column footer
- Compose multiple sections into a coherent page flow
- Apply consistent spacing and visual rhythm across sections

## Topics

### Hero Sections
The first impression. Headline, supporting text, and primary action.

### Feature Sections
Explain value through grouped points or cards.

### Pricing Sections
Compare plans with clear hierarchy and calls to action.

### Testimonials
Social proof through quotes and attribution.

### Footers
Navigation, contact, and secondary information.

### Section Composition
How sections stack into a full-page narrative.
