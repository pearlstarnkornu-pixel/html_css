Specificity & the Cascade

Every example below is a paragraph or heading that has MULTIPLE conflicting rules written against it. Read the CSS file comments to see which rule wins and why.

1. Element vs Class

This text should be GREEN, because the class selector (0-1-0) beats the element selector (0-0-1), even though the element rule is written after the class rule in the stylesheet.

2. Class vs ID

This text should be PURPLE, because the ID selector (1-0-0) beats the class selector (0-1-0).

3. Multiple Classes vs Single Class

This text should be ORANGE with a bold border, because ".badge.urgent" (0-2-0) is more specific than ".badge" (0-1-0) alone.

4. Source Order (Equal Specificity)

This text should be TEAL (the second, later rule), because when specificity ties, the last declaration in the CSS wins.

5. Inline Style vs ID

This text should be BLACK from the inline style attribute, even though #inline-fight below sets the color to red in the external stylesheet. Inline styles outrank ID selectors.

6. !important Overrides Everything (Use Sparingly)

This text should be MAROON because of `!important` on the class rule, overriding the normally-stronger ID rule.
