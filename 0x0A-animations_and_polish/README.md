# 0x0A – Animations & Polish

> Add motion with purpose. Make interfaces feel refined, not noisy.

## Why This Module Matters

Animation is not decoration first — it is feedback.  
Hover states, transitions, and small motion cues help users understand what is interactive, what changed, and where attention should go.

This module teaches practical CSS motion: transitions, transforms, keyframe animations, and polish techniques that improve real UI components and sections. You will also learn restraint, performance awareness, and accessibility (`prefers-reduced-motion`).

## Learning Goals

By the end of this module, you should be able to:

- Use CSS transitions for smooth state changes
- Apply transforms for movement, scale, and elevation effects
- Create simple keyframe animations
- Polish buttons, cards, and links with purposeful motion
- Control timing with duration, delay, and easing
- Respect user motion preferences
- Apply polish without harming usability or performance

## Topics

### Transitions
Smoothly animate property changes between states (hover, focus, active).

### Transforms
Move, scale, and rotate elements efficiently with `transform`.

### Keyframe Animations
Define multi-step motion with `@keyframes`.

### Timing & Easing
Control how motion feels using duration and easing functions.

### UI Polish Patterns
Button hover, card lift, link underline motion, subtle reveals.

### Accessibility
Use `prefers-reduced-motion` so animation never becomes a barrier.
