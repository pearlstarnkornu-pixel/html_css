HTML Lists in Practice

This page shows all three HTML list types, each used for content where that list type genuinely fits.

Features of a Good Study Planner App

An unordered list fits here because the order of these features does not matter.

  • Drag-and-drop weekly calendar for scheduling study sessions
  • Automatic reminders sent before each session begins
  • Progress tracking with charts for completed vs. planned hours
  • Offline mode so notes remain accessible without an internet connection
  • Dark mode for comfortable studying at night

Steps to Set Up the App

An ordered list fits here because these steps must be followed in sequence.

  1. Download the installer from the official website.
  2. Run the installer and accept the license agreement.
  3. Create an account using a valid email address.
  4. Import your class schedule from a calendar file, if you have one.
  5. Set your first study reminder to confirm notifications are working.

Frequently Asked Questions

A description list fits here because each item pairs a term (the question) with its definition (the answer).

Is the app free to use?
Yes, the core scheduling and reminder features are free. A paid tier adds cloud backup and team sharing.
Can I use it on more than one device?
Yes, your account syncs across phone, tablet, and desktop as long as you are signed in.
What happens if I miss a scheduled study session?
The app automatically offers to reschedule the missed session into the next open slot on your calendar.
Does it work without an internet connection?
Yes, offline mode keeps your schedule and notes available; changes sync once you reconnect.

Three list types, three different jobs: unordered for unordered items, ordered for sequences, description for term/definition pairs.
