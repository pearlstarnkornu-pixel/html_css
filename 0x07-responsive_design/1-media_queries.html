Breakpoints in Action

Resize the browser to see each section change at 768px and 1024px.

Zone A

Current breakpoint: Mobile (below 768px)

On a narrow screen this section stacks content in a single column with a warm, compact background so it is obvious you are viewing the base mobile styles.

Zone B

Changes at: 768px and up

At tablet width this section switches to a two-column layout, gets a different background color, and increases its padding.

The text you are reading also grows slightly and the section gains a visible border to mark the change.

Zone C

Changes at: 1024px and up

At desktop width this section moves to a three-column grid, adopts yet another background color, and spacing opens up even further so the page feels intentional rather than merely "big."
