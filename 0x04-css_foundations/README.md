# 0x04 – CSS Foundations

> Turn structure into design. Learn the core rules that control how every webpage looks.

## Why This Module Matters

HTML gives content structure. CSS gives it appearance, hierarchy, and personality.  
Without a solid understanding of the cascade, specificity, the box model, and basic selectors, students struggle with every future styling task.

This module teaches the fundamental rules of CSS so you can style pages intentionally instead of by trial and error. Everything you learn here will be used in Flexbox, Grid, Responsive Design, and component building.

## Learning Goals

By the end of this module, you should be able to:

- Select elements using different types of CSS selectors
- Understand and control the cascade and specificity
- Apply the box model correctly (content, padding, border, margin)
- Use common CSS units appropriately
- Style text and apply colors with confidence
- Write clean, readable CSS
- Style an existing HTML page from scratch

## Topics

### Selectors
How you target HTML elements (element, class, id, attribute, pseudo-classes, combinators).

### Cascade & Specificity
The rules the browser uses to decide which styles win when there are conflicts.

### The Box Model
Every element is a box made of content + padding + border + margin. Understanding this is essential for layout.

### Units
px, %, em, rem, and when to use each.

### Colors & Typography
Setting colors, font families, sizes, weights, and basic text styling.

### Linking CSS
Internal vs external stylesheets and best practices.
