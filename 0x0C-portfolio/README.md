# 0x0C – Portfolio (Capstone)

> Ship a professional portfolio that showcases everything you have learned.

## Why This Module Matters

This is the capstone of the HTML & CSS track.  
A portfolio is not just another page — it is your public proof of skill. Recruiters, clients, and collaborators often judge your frontend ability by the quality of your own site first.

You will combine structure, components, sections, responsive design, and polish into one cohesive personal site. The goal is a complete, deployable portfolio you can keep improving after the course.

## Learning Goals

By the end of this module, you should be able to:

- Plan and build a complete personal portfolio site
- Present projects with clear hierarchy and visual consistency
- Include about, skills, projects, and contact sections
- Make the portfolio fully responsive
- Apply restrained polish (hover states, subtle motion)
- Optionally add a light/dark theme toggle with pure CSS or minimal JS
- Prepare the site for deployment (GitHub Pages or similar)

## Topics

### Portfolio Information Architecture
Home/hero, about, skills, projects, contact, footer — ordered for clarity and trust.

### Project Showcase
Cards or grid items that communicate what you built, the stack, and the outcome.

### Personal Branding Through UI
Consistent type, color, spacing, and component style that feels like “you.”

### Capstone Quality Bar
Semantic HTML, accessible structure, responsive layout, polished interactions, clean CSS organization.

### Deployment Readiness
Relative paths, working links, and a site that opens correctly when hosted statically.
