# 0x0B – Landing Pages

> Bring structure, components, sections, and polish together into one complete page.

## Why This Module Matters

A landing page is where HTML and CSS skills become a real product surface.  
It combines navigation, hero, features, social proof, pricing/CTA, and footer into one coherent experience.

This module focuses on composition quality: clear page narrative, consistent visual system, responsive behavior, and restrained polish.

## Learning Goals

By the end of this module, you should be able to:

- Plan a landing page as a sequence of purposeful sections
- Combine navigation, hero, features, proof, and CTA effectively
- Keep spacing, type, and components consistent across a full page
- Build a responsive landing page from mobile to desktop
- Apply subtle polish without harming clarity
- Produce a page that feels complete and intentional

## Topics

### Page Narrative
A good landing page guides attention: problem/value → proof → action.

### Section Composition
Reuse section patterns as one system.

### Visual Consistency
Shared spacing, color, radius, and button styles create cohesion.

### Conversion-Oriented Layout
Clear hierarchy, strong CTA placement, and scannable content blocks.

### Responsive Completion
The full page must work well at common breakpoints.
