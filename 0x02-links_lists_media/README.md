# 0x02 – Links, Lists & Media

> Connect content, organize information, and bring pages to life with media.

In this module you will learn how to create links, structure information with lists, and add images and other media to your pages. These are essential skills for building real websites.

## Why This Module Matters

Websites are built on connections. Links connect pages together, lists organize information, and media brings content to life. Without these elements, the web would just be plain text documents.

You'll use links constantly — to connect your own pages, link to external resources, and create navigation. Lists appear everywhere: navigation menus, features lists, ingredients, instructions. Media (images, videos, audio) makes content engaging and communicates ideas that text alone cannot.

This module connects HTML structure (from 0x01) with navigation and rich content, preparing you to build complete multi-page websites.

## Learning Goals

By the end of this module, you should be able to:

## Topics

### Links (`<a>`)

Links are how users navigate the web. You'll learn the `href` attribute for destinations, `target` for opening links in new tabs, and `title` for additional information. You'll also learn about different types of links: external, internal, and email links.

### Lists

Lists organize information clearly. You'll learn unordered lists (`<ul>`) for bullet points, ordered lists (`<ol>`) for numbered sequences, and description lists (`<dl>`) for term-definition pairs. Lists are essential for menus, features, instructions, and more.

### Images (`<img>`)

Images make pages engaging. You'll learn the `src` attribute for the image source, `alt` for accessibility descriptions, and `width`/`height` for dimensions. You'll also understand why the `alt` attribute is required for accessibility.

### File Paths (Relative vs Absolute)

Understanding paths is crucial for linking files. You'll learn the difference between relative paths (links to files in your project) and absolute paths (full URLs to external resources). This is essential for organizing project files.

### Figures and Captions

Figures group media with descriptive captions. You'll learn to use `<figure>` and `<figcaption>` to associate images, diagrams, or code snippets with explanatory text. This improves accessibility and content structure.

### Basic Navigation Structure

Navigation menus are essential for websites. You'll learn to create a `<nav>` element with links to different sections of a page, using ID attributes as targets for smooth internal navigation.
