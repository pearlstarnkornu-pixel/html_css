# 0x01 – HTML Foundations

> Structure comes before style. Every great website starts with solid HTML.

In this module you will learn how to properly structure content using HTML. You will move from basic elements to writing clean, semantic, and accessible markup that forms the foundation for all web development.

## Why This Module Matters

HTML is the backbone of every website. Understanding how to structure content correctly ensures your pages are accessible, maintainable, and SEO-friendly. Semantic HTML also makes it easier to style with CSS and add interactivity with JavaScript later.

You'll use these skills in every project going forward. Whether you're building a personal blog, a portfolio, or a full web application, strong HTML fundamentals are essential.

## Learning Goals

By the end of this module, you should be able to:

- [ ] Write valid HTML5 documents from memory
- [ ] Understand elements, tags, and attributes
- [ ] Use headings in the correct hierarchy without skipping levels
- [ ] Format text appropriately using inline tags
- [ ] Apply semantic HTML (`header`, `main`, `section`, `article`, `footer`, etc.)
- [ ] Follow basic accessibility good practices
- [ ] Build small, well-structured pages that are ready to style

## Topics

### HTML Document Structure

Every HTML document needs a proper foundation. You'll learn the required boilerplate including `<!DOCTYPE html>`, the `<html>` element with the `lang` attribute, the `<head>` section with metadata and title, and the `<body>` where content lives.

### Elements, Tags, and Attributes

HTML is built from elements that are defined by tags. You'll learn the difference between opening and closing tags, self-closing tags, and how attributes like `src`, `href`, and `alt` add functionality and information to your elements.

### Headings and Text Formatting

Headings create the structure of your content. You'll learn to use `<h1>` through `<h6>` in the correct hierarchy. Additionally, you'll explore inline formatting tags like `<strong>`, `<em>`, `<mark>`, `<small>`, `<del>`, `<ins>`, `<sub>`, and `<sup>`.

### Semantic HTML

Semantic elements describe their meaning to both browsers and developers. You'll learn to use `<header>`, `<main>`, `<nav>`, `<section>`, `<article>`, `<aside>`, and `<footer>` to create meaningful document structure.

### Basic Accessibility

Accessibility ensures everyone can use your content. You'll learn about the page language attribute, heading hierarchy, meaningful alt text for images, descriptive link text, and other good practices that make your content more inclusive.

### Comments and Code Organization

Clean, organized code is professional code. You'll learn to use comments effectively and structure your HTML in a readable way.
