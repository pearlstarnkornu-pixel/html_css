The CSS Box Model

Every box below uses background colors and outlines to visualize its content, padding, and border layers separately, plus a margin gap between boxes.

Box 1: content-box (the default)

content-box: width is content ONLY. Padding and border are added on top of the declared width, making the final rendered box larger than 220px.
Second content-box example, same rules, showing the margin gap above separates the two boxes.

Box 2: border-box

border-box: width INCLUDES padding and border. This box is exactly 220px wide no matter how much padding or border it has, which makes layout math much easier.
Second border-box example. Notice both border-box boxes are the same total width, even though their padding differs (see CSS comments).

Box 4: Margin Collapsing Demo

The two paragraphs below both have vertical margin. Adjacent vertical margins between block elements can "collapse" into a single margin (the larger of the two), which is a common box model surprise.

Paragraph A has margin-bottom: 30px.

Paragraph B has margin-top: 20px. The visible gap above is 30px (the larger value), not 50px (the sum), because of margin collapsing.
