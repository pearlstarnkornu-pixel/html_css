Reading at Any Width

Every heading and paragraph on this page is sized with clamp(), so the type scales smoothly as the viewport grows instead of jumping abruptly at a fixed breakpoint.

Why Not Just Use Pixels?

A fixed pixel size looks fine at the width you designed it for, but it does not adapt. Text that is comfortable on a phone often looks tiny stretched across a wide monitor, and text sized for a desktop can overwhelm a small screen. Relative units solve this by tying size to something that already changes with the viewport.

How clamp() Helps

clamp(minimum, preferred, maximum) lets a value grow with the viewport width (the preferred value, usually in vw) while never shrinking below the minimum or exceeding the maximum. The result is type that feels hand-tuned at every width instead of only a couple of fixed breakpoints.

Keeping Line Length Readable

This paragraph sits inside a column capped with a ch-based max-width, so even on an ultra-wide monitor the line length stays around 70 characters, which is close to the sweet spot for comfortable reading.
