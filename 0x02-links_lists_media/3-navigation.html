About Me

I am a front-end developer who enjoys turning rough designs into clean, accessible web pages. I started learning HTML and CSS to build small tools for a local community group, and it grew into a full career interest. This page is a preview section of a personal portfolio site.

Skills

Over the past year I have focused on semantic HTML, responsive layout with CSS Grid and Flexbox, and writing accessible markup that works well with screen readers. I am currently expanding into JavaScript for interactive components.

Projects

Recent work includes a recipe-sharing page, a budgeting tracker layout, and this very set of practice exercises covering links, lists, images, and navigation. Each project focuses on solid structure before adding any visual polish.

Experience

I volunteer maintaining the website for a neighborhood youth soccer league, where I update the game schedule and roster pages every season. That hands-on maintenance work is what pushed me to learn HTML fundamentals properly instead of copying templates.
