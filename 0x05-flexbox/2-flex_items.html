Flex Item Properties

flex-grow, flex-shrink, flex-basis, and the flex shorthand.

1. flex-grow

All three items start from flex-basis: 0 but grow at different rates: 1, 2, and 3 — item 3 ends up three times as wide as item 1.

grow: 1
grow: 2
grow: 3

2. flex-basis

Each item starts from a different base width before any growing/shrinking is applied.

basis: 100px
basis: 200px
basis: 300px

3. flex-shrink

The container is too narrow for all three items at their natural width. Item 2 has flex-shrink: 0, so it refuses to shrink while the others do.

Shrinks normally
flex-shrink: 0 (won't shrink)
Shrinks normally

4. flex shorthand

flex: 1 means "grow and shrink equally, starting from zero width" — a common way to make items split space evenly. The middle item uses flex: 2 to take twice the space.

flex: 1
flex: 2
flex: 1

5. align-self on an individual item

The container centers items by default, but the second item overrides its own cross-axis alignment.

default
align-self: stretch
