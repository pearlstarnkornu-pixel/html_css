Working With Images

This page demonstrates images loaded from a relative path and images loaded from an absolute URL, each with meaningful alt text and explicit dimensions.

Image With a Relative Path

This image is referenced with a relative path, meaning the browser looks for it inside a folder next to this HTML file. Relative paths are ideal for images that belong to your own project, because the link keeps working no matter which domain or folder the whole project is moved to.

File path used: images/study-desk.jpg (relative to this page). This local image file is not actually included in this exercise, so the browser will show the alt text or a broken-image icon instead of the picture — that is expected here.

Image With an Absolute URL

This image is referenced with an absolute URL, a full web address that points to a file hosted on a different server entirely. Absolute URLs are necessary when embedding images you do not host yourself, such as pulling a photo from a placeholder image service.

File path used: https://images.unsplash.com/photo-1470770903676-69b98201ea1c (absolute URL to an external server).

Relative vs. Absolute Paths

A relative path describes the location of a file in relation to the current page, such as images/study-desk.jpg or ../assets/logo.png. Relative paths are shorter, and they automatically keep working if the whole website is moved to a new domain, since they never mention a specific host.

An absolute path, on the other hand, is a complete URL including the protocol and domain, such as https://images.unsplash.com/photo-1470770903676-69b98201ea1c. Absolute paths are required whenever the resource lives on a different server than the page referencing it, but they will break if that external server ever changes its URL structure or goes offline.

As a rule of thumb: use relative paths for files that belong to your own project (your own images, stylesheets, and scripts), and use absolute paths only for resources hosted elsewhere.

Every image above includes descriptive alt text, and explicit width/height attributes to prevent layout shift while the image loads.
