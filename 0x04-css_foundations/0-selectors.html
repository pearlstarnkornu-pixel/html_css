Element Selector

Class Selector

This paragraph also uses .highlight, because classes are reusable across many elements.

ID Selector

Card Title

This paragraph is a descendant of .card, so the descendant combinator .card p styles it with italic text.

This paragraph is nested two levels deep inside .card-footer inside .card. The descendant combinator still reaches it, but the child combinator .card > p would NOT, since it isn't a direct child of .card.
