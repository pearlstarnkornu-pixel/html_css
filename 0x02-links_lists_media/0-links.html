External Resources

When researching HTML, one of the most reliable references is the MDN Web Docs HTML reference, which documents every element and attribute in detail. For checking whether a page's markup is valid, the W3C Markup Validation Service is a useful free tool that catches structural mistakes before they cause rendering issues.

Both of these links open in a new browser tab so readers do not lose their place on this page. The rel="noopener noreferrer" attribute is included for security: it prevents the newly opened page from gaining access to this page's window object and stops it from seeing which page referred it.

Internal Page Sections

Internal links point to an element elsewhere on the same page using that element's id attribute. For example, the explanation of list types below is reached without ever leaving this document, and the browser simply scrolls the matching section into view.

Why Internal Links Matter

Long documents, such as terms of service pages or in-depth articles, often use internal links at the top to build a mini table of contents. This lets a reader skip straight to the part they care about instead of scrolling through unrelated content first.
